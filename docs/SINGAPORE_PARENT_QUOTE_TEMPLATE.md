# APC Singapore Parent Quote Template

Status: Internal template for upcoming Singapore enquiries. If CJ has already clearly quoted or accepted another price, honour the existing quote unless scope changes.

## Option 1 - One-Concern Parent Session

**Autism Pathways Consulting**
**APC One-Concern Parent Session**

**Professional fee: S$200**
**Format: Online**
**Duration: 60 minutes**

### Best fit
For one repeated concern when the parent wants help understanding the pattern and deciding what to try first.

### Included
- structured pre-session intake reviewed by CJ,
- 60-minute focused parent consultation,
- review of one clearly defined recurring concern,
- one working explanation / hypothesis, labelled as a working hypothesis,
- one agreed priority,
- 1-2 practical changes to test,
- guidance on what to observe,
- APC One-Concern Action Note within 2 working days,
- one clarification message within 7 days about the agreed plan.

### Scope
This is parent education and practical support planning. It is not diagnosis, therapy or clinical treatment.

### Payment
After CJ confirms suitability, capacity and availability in writing, APC sends the relevant Wise bank-transfer details privately. The booking is confirmed after payment is verified.

### Validity
This quotation is valid for [14] days from the issue date unless otherwise stated.

## Option 2 - Home Implementation Programme

**Autism Pathways Consulting**
**APC Home Implementation Programme**

**Programme fee: S$980**
**Format: Online**
**Duration: Four 60-minute sessions across approximately 6-8 weeks + maintenance check**

### Best fit
For concerns that need implementation, review and adjustment over time rather than one piece of advice.

### Included
- structured baseline intake,
- 1-2 agreed family priorities,
- four 60-minute private online sessions,
- personalised APC Home Support Plan,
- What We're Testing cards,
- brief between-session implementation check-ins,
- bounded WhatsApp clarification during the active programme,
- relevant APC implementation tools where useful,
- review and adjustment of the plan across sessions,
- progress snapshot,
- APC Maintenance Summary,
- 20-30 minute maintenance check approximately one month after Session 4.

### Service standards
- Initial Home Support Plan targeted within 2 working days after Session 1.
- Final Maintenance Summary targeted within 3 working days after Session 4.
- Brief WhatsApp clarification target response within 2 working days during the active programme.

### Scope
This is parent education and implementation support. It is not diagnosis or therapy. The programme does not include delivery of Hanen, Teacher Talk™, Learning Language and Loving It™, ABC and Beyond™ or an official SCERTS programme.

### Payment
After CJ confirms suitability, capacity and availability in writing, APC sends the relevant Wise bank-transfer details privately. The programme is confirmed after payment is verified.

If APC later offers instalment payment, it must be written explicitly in the individual quote. Do not assume an instalment option unless stated.

### Validity
This quotation is valid for [14] days from the issue date unless otherwise stated.
