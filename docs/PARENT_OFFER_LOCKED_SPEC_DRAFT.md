# APC Parent Offer Locked Spec - Draft

Status: Internal decision-ready specification. Do not publish new prices until CJ approves the effective date and public migration.

## 1. Offer architecture

APC keeps three parent routes only:

1. Free 15-Min First Step Call
2. APC One-Concern Parent Session
3. APC Home Implementation Programme

Do not add extra Bronze/Silver/Gold tiers at this stage.

## 2. Free 15-Min First Step Call

### Problem solved
“I am not sure whether APC is the right route or what I should book.”

### Standard inclusion
- 15-minute phone call.
- Fit and routing only.
- Parent should leave knowing:
  - whether the concern is within APC's scope,
  - which APC route, if any, is the best fit,
  - whether another professional route may be more appropriate,
  - the next step if they continue.

### Not included
- personalised strategy plan,
- diagnosis,
- assessment,
- therapy,
- detailed formulation,
- ongoing messaging.

## 3. APC One-Concern Parent Session

### Draft price
Malaysia: **RM450**
Singapore: **S$200**

### Problem solved
“One repeated situation keeps happening and I do not know what matters most or what to try first.”

### Standard inclusion
- structured pre-session intake,
- CJ reviews intake before the call,
- 60-minute private online consultation,
- focus on one clearly bounded recurring concern,
- pattern review,
- one working explanation / hypothesis, explicitly labelled as a working hypothesis,
- one agreed priority,
- 1-2 practical changes to test,
- guidance on what to observe next,
- APC One-Concern Action Note,
- one clarification message within 7 calendar days about the agreed concern/plan only.

### Recommended service standard
- Action Note sent within 2 working days after the session.
- Clarification reply target: within 2 working days.

### Optional / only when relevant
- selected APC public resource links,
- brief referral / coordination note,
- “Who Does What” consistency tool if several adults need one response,
- minimum-version strategy for high-stress/busy days.

### Not included
- a second/new concern,
- unlimited WhatsApp,
- school observation,
- clinical assessment,
- therapy,
- formal clinical report,
- Hanen / ABC / LLLI / Teacher Talk delivery,
- official SCERTS programme delivery.

## 4. APC Home Implementation Programme

### Draft price
Malaysia: **RM2,400**
Singapore: **S$980**

### Problem solved
“We know some of the advice, but we need help making a plan work consistently in real life and changing it when it does not fit.”

### Standard inclusion
- structured baseline intake before Session 1,
- 1-2 agreed priorities,
- four 60-minute online sessions across approximately 6-8 weeks,
- personalised APC Home Support Plan,
- “What We're Testing” card after each implementation decision,
- brief between-session implementation check-ins,
- bounded WhatsApp clarification during the active programme,
- Keep / Adjust / Stop review,
- minimum-version strategy where useful,
- selected APC implementation tools where useful,
- plan review and adjustment across sessions,
- progress snapshot,
- final APC Maintenance Summary,
- 20-30 minute maintenance check approximately one month after Session 4.

### Recommended service standards
- Initial Home Support Plan sent within 2 working days after Session 1.
- Material plan updates incorporated after review sessions when the agreed approach changes.
- Final Maintenance Summary sent within 3 working days after Session 4.
- WhatsApp reply target: within 2 working days during the active programme.

### Optional / only when relevant
- Who Does What consistency plan,
- routine map,
- prompting/independence reflection,
- selected existing APC resources,
- parent-approved Shareable Support Summary for school / other professionals,
- referral / coordination questions for another professional.

### Not included
- unlimited messaging,
- unlimited topic changes,
- emergency/crisis support,
- formal diagnostic or therapy services,
- automatic school liaison,
- formal clinical reports,
- delivery of Hanen, ABC, LLLI, Teacher Talk or official SCERTS curricula.

## 5. Programme journey

### Before Session 1
Baseline + define meaningful family priorities.

### Session 1 - Understand
Map the situation, agree first working hypothesis and first practical change.

### Between sessions
Parent tries the agreed plan and records only the minimum useful observations.

### Session 2 - Review
Check what actually happened, including whether the plan was usable.

### Session 3 - Build
Adjust, generalise or improve consistency without automatically adding more goals.

### Session 4 - Consolidate
Decide what to keep, adjust or stop and create a maintenance plan.

### About one month later
20-30 minute maintenance check.

## 6. Usability promise

Recommended wording:

“If the agreed plan is not practical enough to use in your family's real routine, we review and adjust it rather than expecting you to keep forcing a plan that does not fit.”

This is not an outcome guarantee.

## 7. Scope statement

APC provides parent education, pattern review, practical support planning and implementation guidance.

APC does not provide diagnosis, speech-language therapy, psychological treatment, medical care or crisis services.

## 8. Existing-client transition rule

- Existing paid clients keep the package/price already agreed.
- Active RM1,800 clients are not repriced mid-programme.
- Existing written quotes remain valid for their stated validity period.
- New pricing begins only from a clearly chosen public effective date.

## 9. Evidence to collect after launch

Track:
- whether the parent used the agreed plan,
- whether it felt practical,
- barriers to implementation,
- parent clarity/confidence about the next step,
- whether adults became more consistent,
- whether the family needed another adjustment,
- whether the written deliverables were used,
- conversion and price objections,
- referrals / repeat review demand.

Do not convert these into pseudo-clinical outcome scores.
