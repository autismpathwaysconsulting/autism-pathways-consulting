## 7. What ChatGPT will do autonomously after Batch 1

Using only the uploaded current materials as the programme-content authority, ChatGPT can:
- identify the exact programme version,
- build a session map,
- extract required learning objectives,
- build CJ-only trainer notes,
- map activities/media/timing,
- identify mandatory vs optional elements,
- identify fidelity/copyright restrictions,
- create a concept quiz grounded in the materials,
- create difficult participant Q&A,
- create a materials/workbook checklist,
- build a timed rehearsal plan,
- score CJ against the readiness rubric,
- red-team common mistakes and overclaims.

If the material does not support a claim, ChatGPT should say so rather than fill the gap from general knowledge.

## 9. Privacy / copyright handling

These materials are for CJ's private licensed programme preparation.

Do not:
- publish the files,
- create public downloads from them,
- reproduce member-only slides/handouts in APC public content,
- turn Hanen material into an APC-owned paid course.

Public-facing APC content should remain independently created or use Hanen-approved promotional material where permitted.
