# APC Parent Intake + Implementation Impact Tracker

Status: Internal operating template. This is not a clinical assessment instrument.

## 1. One-Concern pre-session intake

Collect only what is needed to make one focused session useful.

### Parent / family
- Parent name
- Country / time zone
- Child age
- Current professionals involved, optional brief list

### One concern
- What keeps happening?
- In which routine / situation is it most likely?
- What tends to happen immediately before it?
- What does the child do during it?
- What usually happens immediately after?
- What have you already tried?
- What is the hardest part for you as the parent?
- If this session is useful, what would you leave clearer about?

Instruction: Do not upload diagnostic reports or long histories unless CJ specifically asks for them.

## 2. One-Concern end-of-session record

Internal fields:
- Concern statement
- Important verified facts
- Parent-reported patterns
- Working hypothesis / alternative hypotheses
- Agreed priority
- Action 1
- Action 2, if needed
- What to observe
- Referral / safety boundary
- Action Note due date

## 3. One-Concern lightweight impact check

Use after the session / clarification window where practical.

Questions:
1. Was the Action Note clear enough to use? Yes / partly / no
2. Did you try the agreed action? Most opportunities / some / not yet
3. What got in the way, if anything?
4. Do you feel clearer about what to try next? 1-5
5. Do you need another APC review, another professional route, or no further support now?

Purpose: measure usefulness and implementation, not child treatment outcome.

# Home Implementation Programme

## 4. Baseline intake before Session 1

### Family priorities
- What are the 1-2 situations that currently create the most difficulty at home?
- Which one matters most to address first?
- What would meaningful improvement look like in everyday life?
- Who is involved in this routine? Parent / co-parent / helper / grandparent / sibling / other
- What support is already in place?
- What have you tried before?

### Context
For each priority:
- when / where it usually occurs,
- common triggers / demands / transitions,
- what adults usually do,
- what makes it easier,
- what makes it harder,
- relevant school / professional input already available.

### Family feasibility
- How much time/energy can the family realistically put into the plan?
- What would make a plan too difficult to sustain?
- Which adult needs the simplest version?

## 5. Session 1 baseline snapshot

Record:
- priority 1,
- priority 2 if needed,
- parent clarity 1-5,
- current consistency across adults 1-5,
- current ease of using existing support 1-5,
- brief description of what is happening now,
- first plan,
- minimum version,
- what to observe until Session 2.

These ratings are internal implementation indicators, not validated clinical scores.

## 6. Between-session implementation check

Keep this to approximately 2 minutes.

1. Did you try the agreed plan?
   - most opportunities
   - some opportunities
   - not yet

2. If not consistently, what got in the way?
   - forgot
   - too complicated
   - different adults responded differently
   - routine changed
   - child's response made it hard to continue
   - we were unsure what to do
   - other

3. What happened when you did try it?

4. Which part felt easiest?

5. Which part needs review at the next session?

## 7. Review-session record

For Sessions 2-4:
- Was the plan actually implemented?
- What changed in the context?
- What did the family learn?
- KEEP
- ADJUST
- STOP
- current minimum version
- next test
- what to observe
- whether another professional should be involved.

## 8. Progress snapshot

At midpoint and final session compare:
- parent clarity about what to do: 1-5
- consistency across adults: 1-5
- ease/practicality of the plan: 1-5
- confidence noticing when the plan needs adjustment: 1-5
- whether the family is using the plan: most / some / not yet
- family-described changes in the routine / participation / independence, where relevant
- unresolved concern(s)

Do not describe these as diagnostic, symptom-severity or treatment-outcome scores.

## 9. Maintenance check approximately one month later

Ask:
- What are you still using?
- What has drifted or stopped?
- What is easier now?
- What still feels difficult?
- Has the family changed the plan on its own successfully?
- Is the original priority still the right priority?
- Does the family need:
  - no further support,
  - a focused Progress Review later,
  - another APC implementation cycle,
  - another professional / service?

## 10. Business / service-quality metrics

Track across clients:
- enquiry source,
- Malaysia / Singapore / other,
- service chosen,
- quoted price,
- price objection yes/no + reason,
- completion rate,
- Action Note / Plan delivered on time,
- amount of between-session messaging,
- implementation rate,
- usability rating,
- referral out rate,
- client referral/recommendation,
- repeat review demand,
- approximate practitioner time spent beyond live sessions.

Use this data to improve the service and pricing. Do not turn it into unsupported claims about child developmental outcomes.
