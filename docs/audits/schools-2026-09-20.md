# Schools page audit, 20 September 2026

Scope: Schools page on draft PR #82, using the current homepage as the visual reference. Preview only. The homepage's status as the strongest design is Founder feedback, not a measured benchmark. No installed /loopmax command was available; a check, repair and recheck audit was used.

## Changes and repairs

- Richer mint, coral and aqua illustration panels, preserving APC teal, cream, paper-like materials and soft shadows. Homepage artwork retained.
- More consistent section/card spacing, wrapping section heading, and stacked tablet enquiry fields. Mobile cards remain large native disclosure controls.
- Responsive homepage-image sources reduce unnecessary mobile image transfer.
- Topic links now select the matching training focus and focus that control without replacing the visitor's free-text description. The normal anchor still targets the form.
- Editing any form field or choosing another topic invalidates the old prepared WhatsApp message. Submission still only prepares a link for review; it does not send a message.
- Added autofill hints and a programmatic connection between the message field and privacy instructions.

## Limitations and remaining checks

Full-page browser rendering, keyboard operation in a real browser, animation smoothness, zoom, narrow-screen overflow, external-link HTTP availability, and measured performance remain unverified in this pass. No cloud browser was used, respecting the existing preference. Automated DOM simulations and CSS inspection do not replace these checks. No Lighthouse, accessibility conformance, Google ranking or numeric design score is claimed.

The broader authority validator still reports four baseline findings: `pathways-lab/app.js`, `pathways-lab/model.js`, `scripts/episode-preview.mjs`, and `tests/pathways-lab.test.mjs`, all `authority.executable_javascript_forbidden`. They are unrelated to this Schools revision and were not changed.
