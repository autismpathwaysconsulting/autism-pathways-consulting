# APC Parent Communication Boundaries

Status: Internal operating policy draft. Use to standardise RM450 / S$200 One-Concern and RM2,400 / S$980 Home Implementation support.

## 1. General rule

Messaging exists to support implementation of an agreed plan. It is not an unlimited access channel, a replacement for a scheduled session, or an emergency service.

## 2. One-Concern Parent Session

### Included
One clarification message from the parent within 7 calendar days after the session.

The message may ask for clarification about:
- the agreed priority,
- the 1-2 actions already discussed,
- the Action Note,
- what the parent was meant to observe.

### Not included
- a new concern,
- a detailed new case update requiring fresh analysis,
- repeated back-and-forth coaching,
- urgent/crisis support,
- document review not agreed in the session.

### Response target
CJ aims to reply within 2 working days.

### Boundary response if scope expands
Suggested reply:

“Thanks for the update. This goes beyond clarifying the plan we agreed in the One-Concern Session and would need a fresh review rather than a quick message. We can decide whether another focused session or a longer implementation programme is the better fit.”

## 3. Home Implementation Programme

### Included during active programme
Parents may use WhatsApp for brief implementation clarification about the 1-2 agreed priorities.

Examples:
- “We tried the agreed step but this part is unclear.”
- “The routine changed this week. Should we keep the same minimum version until the next session?”
- “Here is the brief observation you asked us to track.”

### Not included
- unlimited daily coaching,
- immediate/on-demand replies,
- emergency support,
- repeated analysis of long videos,
- adding unrelated concerns between sessions,
- directing schools/other professionals without a separate agreed scope,
- long case-history discussions that should happen in-session.

### Response target
CJ aims to respond within 2 working days during the active programme.

### Active-programme window
Begins after Session 1 and ends after the scheduled 30-day maintenance check, unless the agreement states otherwise.

## 4. Emergency / urgent matters

APC is not an emergency or crisis service.

For immediate danger, serious injury, acute medical concerns, severe mental-health crisis or other urgent risk, the family should contact the appropriate local emergency / medical / crisis service rather than wait for an APC reply.

## 5. Privacy

Parents should avoid sending unnecessary identifying, medical or highly sensitive information through casual messaging.

If a file, video or document is genuinely needed, CJ should confirm the purpose and appropriate channel before the family sends it.

## 6. Videos

No routine promise of video review is included in either parent package.

If CJ specifically requests a brief video/example for educational observation, the purpose, transfer method, retention and privacy handling should be agreed first.

## 7. New concerns

A new concern should not silently replace the original paid scope.

For Home Implementation:
- new information related to the same 1-2 priorities may be reviewed,
- a materially different concern should be parked for later, referred, or scoped as separate support.

## 8. Messaging tone

Keep replies:
- concise,
- practical,
- tied to the agreed plan,
- clear about uncertainty,
- non-diagnostic,
- explicit when a question requires a scheduled review.

## 9. Client-facing short wording

### One-Concern
“One clarification message within 7 days is included for questions about the agreed plan. This does not cover a new concern or ongoing coaching.”

### Home Implementation
“Brief WhatsApp clarification is included during the active programme for the agreed priorities. Replies are not immediate, and WhatsApp is not an emergency service or an unlimited coaching channel.”
