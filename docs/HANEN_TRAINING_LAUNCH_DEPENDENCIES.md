# Hanen Training Launch Dependencies

Purpose: prevent APC from advertising or accepting paid programme delivery before the required content, licence, operational and commercial gates are complete.

## 1. Teacher Talk A

### Already complete
- LLLI / Teacher Talk delivery right verified at business-planning level.
- School/educator enquiry route built.
- B2B enquiry playbook built.
- Institutional pricing hypothesis built.
- Meeting/demo framework built.
- B2B terms draft built.
- claim-safety rules built.
- readiness rubric structure built.
- participant registration/attendance/evaluation/admin pack built.
- buyer objection bank built.
- private study workspace structure built.
- public Hanen evidence/positioning pack built from current public sources.
- materials upload manifest built.
- video/privacy draft built for programmes that require recording/feedback.

### Waiting for current materials
- latest Leader Guide review,
- latest slides review,
- workbook/material requirements verification,
- exact mandatory content / activities / timing,
- online/in-person implementation details,
- exact participant completion/documentation rules.

### Waiting for Hanen clarification where relevant
- participant certificate/documentation wording,
- promotional assets / mark use,
- cross-border delivery clarification,
- HRD Corp use of licensed programme material if later pursued.

### Requires CJ personally
- study/revision,
- knowledge quiz,
- timed rehearsal,
- difficult Q&A rehearsal,
- final delivery confidence approval.

### Paid-launch gate
All must be true:
- current materials reviewed,
- no material fidelity uncertainty,
- readiness >= 8.5/10,
- zero critical fail findings,
- participant materials available,
- price/quote approved,
- terms/cancellation/payment ready,
- delivery format/venue/tech ready,
- participant documentation rule confirmed,
- attendance/evaluation/admin workflow ready,
- public claims checked against current programme/licence information.

## 2. Teacher Talk B / C

Dependencies:
- Teacher Talk A already delivery-ready,
- current B/C materials uploaded and reviewed,
- Training A prerequisite rules confirmed,
- separate content mastery/rehearsal for each training,
- B/C specific material/workbook logistics confirmed.

Do not assume readiness for B/C merely because A is ready.

## 3. ABC and Beyond™

### Can start after materials upload
- verify current full-programme structure,
- verify authorised module options,
- verify age/audience requirements,
- verify required individual video-feedback elements,
- map full vs module delivery workload,
- create separate pricing model based on actual feedback workload,
- finalise video privacy/consent operations.

### Paid-launch gate
- current materials reviewed,
- chosen format is an authorised format,
- required video feedback operationally safe,
- participant documentation confirmed,
- CJ rehearsal/readiness passed,
- price reflects group + individual feedback workload,
- participant admin/evaluation process adapted to the actual ABC format.

## 4. Learning Language and Loving It™

Highest operational complexity of the current educator portfolio.

Dependencies:
- current Leader Guide/slides/online materials uploaded,
- full programme structure/fidelity verified,
- mandatory group-session hours confirmed,
- mandatory individual video feedback confirmed,
- participant maximum/minimum/material rules confirmed,
- secure video handling process finalised,
- scheduling capacity modelled per participant,
- quote built from actual workload rather than simple live-hour rate,
- CJ full rehearsal/readiness passed,
- participant administration accounts for multi-session attendance and individual feedback.

## 5. School enquiry launch versus paid-course launch

### Enquiry-only launch
Can proceed once website visual/smoke QA passes.

This allows APC to:
- learn what schools actually need,
- collect buyer language,
- test whether Hanen recognition matters,
- test HRD demand,
- estimate cohort sizes,
- identify preferred delivery formats.

### Paid-course launch
Requires programme-specific readiness above.

Do not conflate an enquiry-ready website with trainer delivery readiness.

## 6. Cross-border delivery

Before accepting delivery outside Malaysia:
- confirm Hanen territorial/licence permission for the exact programme and format,
- check local professional/regulatory scope,
- check privacy/data-transfer requirements if classroom video is involved,
- confirm tax/payment/logistics.

Do not advertise worldwide availability as a blanket claim.

## 7. Recognition path after first pilot

After real institutional demand and one or more successful cohorts:
- collect implementation feedback,
- determine whether buyers require HRD Corp,
- consider HRD trainer/provider pathway if commercially justified,
- consider APC-owned separately accredited educator courses later,
- keep Hanen programme-owner IP separate from APC-owned accreditation efforts.

## 8. Stop rule

Do not add a new certification/course to the immediate plan until APC has tested demand for the current licensed portfolio.

The current bottleneck is readiness + demand validation, not shortage of credentials.
