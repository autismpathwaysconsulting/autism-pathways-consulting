## 3. Material intake checklist

For every uploaded file record:
- programme,
- document title,
- version/date,
- file type,
- current/obsolete/unknown status,
- whether it is trainer-only,
- whether it contains participant-facing material,
- restrictions stated in the document,
- pages/sections most relevant to delivery readiness.

If two current-seeming documents conflict, do not silently reconcile. Flag the conflict and seek the newer official source/written Hanen clarification.

## 4. Session-map template

For each session/block:
- objective,
- required content,
- required activity/media,
- participant task,
- facilitator task,
- key transition,
- time allocation,
- fidelity-critical element,
- optional/contextual element if explicitly allowed,
- common participant question,
- likely timing risk.

## 5. Trainer-cue template

For each concept:
- one-sentence plain-language explanation,
- why it matters,
- example allowed for CJ's private rehearsal,
- question to ask participants,
- common misconception,
- what not to say,
- scope/copyright caution if relevant.

Do not paste full slide text into public or buyer-facing materials.

## 6. Knowledge quiz structure

Question types:
- core concept recall,
- audience/eligibility,
- programme sequence,
- timing,
- required materials,
- required activity/video,
- fidelity/adaptation limits,
- participant documentation,
- recording/copyright,
- difficult real-world application,
- scope boundary.

Scoring:
- 90%+ factual score target,
- no critical fidelity/scope error,
- every wrong answer triggers re-study and re-test.

## 7. Q&A bank structure

Categories:
- beginner participant questions,
- skeptical participant questions,
- school-leader questions,
- difficult/edge-case classroom questions,
- questions that should be deferred to another professional,
- questions that risk turning the training into clinical SLT advice,
- questions about adaptation/recording/certification.

Each answer should be tagged:
- `PROGRAMME_VERIFIED`
- `HANEN_WRITTEN_CONFIRMATION`
- `PUBLIC_EVIDENCE`
- `CJ_PROFESSIONAL_JUDGEMENT`
- `DEFER / VERIFY`

## 8. Rehearsal structure

### Section rehearsal
Run one block at a time.
Check:
- accuracy,
- clarity,
- timing,
- natural delivery,
- activity instructions,
- transition,
- question handling.

### Full rehearsal
Simulate the full programme/training with breaks and activities.
Track:
- start/end time,
- overruns,
- rushed content,
- participant engagement points,
- technology/logistics risks.

### Hostile Q&A rehearsal
CJ must answer without overclaiming, improvising licensure claims or drifting outside scope.

## 9. Readiness evidence folder

Keep records of:
- latest quiz score,
- weak areas,
- full rehearsal timing,
- critical errors found/corrected,
- final fidelity checklist,
- material/logistics readiness,
- certificate/documentation confirmation,
- final readiness sign-off.

## 10. Final gate

A programme is not "ready" merely because the materials exist.

Minimum:
- current materials verified,
- content map complete,
- quiz passed,
- Q&A passed,
- timed rehearsal passed,
- fidelity checklist passed,
- operational/admin materials ready,
- promotion/certificate claims verified,
- no critical scope/copyright issue.
