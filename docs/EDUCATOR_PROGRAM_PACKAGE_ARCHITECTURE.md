# APC Educator Programme Package Architecture

Status: INTERNAL PACKAGE ARCHITECTURE. Pricing is intentionally left separate. Programme-content fidelity and exact delivery details must be verified against the current licensed Hanen materials before paid dates are accepted.

Purpose: make each educator programme easy for a school/centre to understand and buy as a complete implementation package, rather than selling only “training hours”.

## 1. Packaging principle

Every institutional programme should be sold as a complete buying container with four layers:

1. **Buyer alignment** — clarify the organisation's actual problem, cohort and expected practice change.
2. **Official programme delivery** — deliver the licensed Hanen programme exactly within current programme-owner requirements.
3. **Implementation bridge** — help the organisation decide what educators will actually apply after training, without altering or repackaging Hanen content.
4. **Review** — a clearly separate APC implementation follow-up where useful, to check whether agreed practices are being used and what barriers remain.

The Hanen programme and any APC implementation follow-up must remain visibly distinct.

## 2. Teacher Talk™ Training A Institutional Package

### Best when
An early-childhood organisation wants a focused first step in strengthening everyday educator interaction and language-support practice.

### Official programme component
- Teacher Talk™ Training A delivered by CJ within current Hanen licence/fidelity requirements.
- Current verified duration: 7.5 PD hours.
- Current verified format: online or in person within Hanen requirements.
- Current verified participant maximum: 24 online / 30 in person.
- Each participant requires the applicable Teacher Talk workbook/materials as required by Hanen.

### APC package wrapper
Before delivery:
- 20–30 minute buyer alignment call,
- confirm participant roles / age group / setting,
- identify the organisational problem the buyer wants the training to address,
- confirm format, cohort size, materials and logistics,
- participant registration + attendance process.

During delivery:
- official Teacher Talk A only,
- no APC modification of Hanen teaching content,
- participant questions kept within programme/scope boundaries.

After delivery:
- participant evaluation,
- attendance/completion documentation according to confirmed Hanen rules,
- concise buyer implementation summary based on participant feedback and agreed organisational priorities,
- optional separate APC implementation review approximately 4–6 weeks later.

### Buyer outcome
The organisation receives a completed licensed training event plus a clear implementation bridge, rather than a workshop that ends when the slides finish.

## 6. APC Autism-Specific Educator Implementation Package

This is separate from Hanen and can be APC-owned.

### Best when
The buyer's main problem is autism-specific implementation rather than early-language or emergent-literacy professional development.

Potential problem areas:
- inclusion and participation,
- regulation / overwhelm,
- routines and transitions,
- prompting and independence,
- consistency across staff,
- parent-school alignment,
- implementation review.

### Package structure
- buyer problem-definition call,
- APC-owned professional-development session/workshop scoped to the agreed problem,
- practical action plan,
- implementation follow-up after an agreed period,
- buyer summary of barriers / next steps.

Do not use Hanen or SCERTS proprietary content as APC-owned training material.

## 7. What is standard versus optional

### Standard for institutional packages
- buyer alignment call,
- programme/participant fit confirmation,
- official training delivery,
- participant administration,
- required materials handling,
- attendance/evaluation,
- post-delivery buyer summary.

### Optional / separately scoped
- travel / accommodation,
- extra implementation review,
- school observation,
- leadership consultation beyond the package,
- repeated coaching cycles,
- custom APC workshops,
- HRD Corp administration if pursued later.

Do not hide substantial delivery costs inside “free bonuses”.

---

## 8. Pricing architecture (not final prices)

Pricing should be built from:
- programme delivery time,
- preparation/admin time,
- required individual feedback/coaching load,
- participant materials at actual landed cost,
- travel/venue costs where applicable,
- post-programme implementation review if included,
- cohort size and programme-owner limits.

Teacher Talk may be priced as an institutional cohort fee plus materials/logistics.

ABC and LLLI must not be priced only by live group hours because individual video-feedback workload is material.

Do not publish final programme prices until current materials are reviewed and delivery workload is modelled.

## 10. Launch rule

A programme package may be described at enquiry level before final price is set.

A paid delivery date should only be accepted once:
- current licensed materials are reviewed,
- exact programme format and workload are verified,
- CJ passes the readiness gate,
- participant materials/admin are ready,
- any unresolved certificate/promotion/territory issue is either answered by current authoritative materials or clearly excluded from claims,
- quote/terms/privacy requirements are complete.
