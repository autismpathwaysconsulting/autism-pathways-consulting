# APC Parent Implementation Toolkit

Status: APC-owned client resource draft. This toolkit is intentionally original and must not reproduce Hanen, SCERTS or other proprietary programme materials.

Purpose: give parents simple tools to use between APC sessions without turning family life into constant data collection.

## Tool 1 - One-Minute Pattern Check

Use only when a repeated situation happens.

**Before**
What was happening immediately before?

**During**
What did my child do?

**Adult response**
What did I/we do next?

**After**
What happened afterwards?

**Anything different today?**
Sleep, illness, schedule change, unfamiliar person/place, unusual demand, hunger, sensory load, etc.

Rule: one short entry is enough. Do not record every incident unless CJ specifically asks for a brief baseline sample.

## Tool 2 - Implementation Check

At the end of a few days, ask:

1. Did we actually use the agreed change?
   - Usually
   - Sometimes
   - Rarely

2. Where was it easiest to use?

3. Where was it hardest?

4. What got in the way for the adults?

5. Did the situation change in any noticeable way?

6. Did anything become more difficult or distressing?

This distinguishes 'the strategy did not work' from 'we did not yet manage to use it consistently'.

## Tool 3 - Keep / Adjust / Stop

Before each review session:

### KEEP
What seems useful enough to continue?

### ADJUST
What may need changing because the context, timing, demand or adult response does not fit?

### STOP
What are we doing that adds effort without helping, or appears to make the situation worse?

### STILL UNCERTAIN
What do we not yet understand?

## Tool 4 - Independence Check

For one routine only:

What can the child already do without help?

Where do adults usually step in?

Which prompt is currently used?
- environmental cue
- visual cue
- gesture
- brief verbal cue
- model
- physical guidance

Where could we pause slightly longer before helping?

What would count as a meaningful small increase in independence?

This is not a formal assessment or prescribed prompting hierarchy. It is a planning tool for noticing where adult support may be more or less necessary.

## Tool 7 - Maintenance Check

Use about one month after the active implementation cycle.

- Are we still using the plan?
- Has it become easier to use?
- Is the concern still the same?
- Has the child's context changed?
- Are adults drifting back to an older response?
- Is the plan no longer needed?
- Is there a new issue that should be treated as a separate concern?
- Would another professional be more appropriate now?

## Packaging recommendation

### RM450 One-Concern Parent Session
Include only:
- One-Minute Pattern Check, if useful
- the One-Concern Action Note

Do not overwhelm a one-off client with the full toolkit.

### RM2,400 Home Implementation Programme
Include the full relevant toolkit selectively.

CJ chooses only the worksheets that match the active priority. The value comes from using the right tool, not giving the parent a thick workbook.

## Scope note

These tools support parent education, observation, implementation and reflection. They are not diagnostic measures, clinical assessments, therapy protocols or substitutes for professional evaluation where needed.
