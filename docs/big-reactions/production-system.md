# Big Reactions production system

## Recording
- iPhone at eye level.
- DJI Mic Mini on upper chest.
- Record in 30 to 90 second blocks.
- Use a simple real room background.
- Turn off unflattering overhead lights where possible.
- Use one soft key light around 30 to 45 degrees from camera.
- Leave negative space beside CJ for graphics.

## Editing
- Existing local audio cleanup first.
- CapCut Desktop is the main visual editor.
- Canva is used for selected diagrams and worksheet visuals.
- AI supports cleanup and asset creation, not the presenter identity.

## Visual rhythm
Use a meaningful visual change roughly every 15 to 30 seconds:
- talking head;
- talking head plus one phrase;
- side graphic;
- full-screen diagram;
- worksheet walkthrough;
- simple animated example.

## Production test
Create one 45 to 60 second finished test before producing all lessons.
Pass only if:
- voice sounds natural;
- skin tone looks natural;
- graphics remain readable on mobile;
- animations support the teaching;
- the result does not look AI-generated.
