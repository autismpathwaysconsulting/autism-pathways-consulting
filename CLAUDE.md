# APC website: working rules for this repo

Static HTML site for Autism Pathways Consulting (APC), founded by CJ Lim (MA Special and
Inclusive Education). Edit HTML/CSS in place, then run the allowlisted `npm run build` release step. The site is now
`LAUNCHED / LIVE` and public. Production deployment, merge, and marking a draft PR ready for
review still require separate Founder authorization for any further changes.

APC-AI-OS is the canonical offer authority. On 2026-10-20 the Founder approved a repositioning for
parents, centres and schools with the new offer ladder below, which replaces the earlier locked ladder
(One-Concern Parent Session RM350, Home Support RM1,800) and its permission-before-payment wording.
`tests/test_current_offers.py` checks the public pages against this ladder (prices, payment line, dropped
offers, First Step Call). Change offer facts there only when the Founder has given an explicit instruction.

## Non-negotiable brand rules (apply to every change)
- **No em dashes anywhere, ever.** Use commas, colons, or full stops. Before committing, confirm zero em-dash characters remain in changed files (count must be 0).
- **No therapy-replacement, diagnosis, cure, "method/framework", or guaranteed-outcome language.**
  APC is parent education and structured parent support, not therapy, diagnosis, or treatment.
- Tone: warm, calm, practical. Card/guide titles use the parent's felt moment, not a clinical
  topic label (e.g. "When the meltdown comes out of nowhere", not "Meltdowns at home").
- Scope line where relevant: "APC works with you, not instead of the therapists your child is already seeing."
- Parent-facing CTAs should route by readiness rather than forcing every parent through the same path:
  - **Start free:** the free Big Reactions Quick Check (`/big-reactions-quick-check`) is the primary CTA site-wide.
  - **Learn with other parents:** Pattern Session, RM57 live online group. Dates go to the Quick Check email list first.
  - **Ready for the Autism Parent Pathway Programme:** start with the Free 15-Min First Step Call so CJ can check fit.
  - **Centres and schools:** "Ask for a training quote" through the WhatsApp enquiry builder on `/schools`.
- Keep the Free 15-Min First Step Call available on `/parents` as the fit-check path for the Autism Parent Pathway Programme.
- Do not turn the Autism Parent Pathway Programme into unrestricted direct checkout or create a new intake form unless separately approved.

## Visual and UX authority
- `DESIGN.md` is authoritative for visual and UX decisions. Future page work must follow it, preserve the funnel rules, begin mobile-first, and reduce unnecessary visual complexity rather than add it.

## Site conventions
- `/page.html` 308-redirects to extensionless `/page` (and `/index.html` → `/`). Canonical, `og:url`,
  and `sitemap.xml` all use the extensionless form. `pay/index.html` serves `/pay/`.
- Retired routes: `_redirects` sends `/programmes` and `/start` to `/` and `/services` to `/parents`.
  `start.html`, `programmes.html`, `services.html`, `course-waitlist.html` and `connect/index.html` are
  meta-refresh stubs; `services.html` and `parents.html` send `#educator-training` to `/teacher-talk`.
- Payment safety notice: `/pay/` is informational only and exposes no payment instructions, account
  details, QR asset, receipt-submission CTA, or selector. Root `pay.html`, `/pay/350`, and `/pay/1800`
  redirect to that same notice. Individual payment details are sent privately by CJ.
- Brevo email capture: the free Quick Check and the free parent guide (on `resources.html`).
- The Free 15-Min First Step Call is linked from `/parents` (programme card and closing section).
- `apc-design-system.css` is the authoritative shared visual layer for the main parent-facing pages. Load it after page-specific styles so its tokens and consistency overrides apply last.
- Custom `404.html` + `_redirects` (`/* /404.html 404`). Accessibility baseline: `<style id="apc-a11y">`,
  a skip link, and `id="main-content"` on each `<main>` already exist on live pages; do not re-add.

## Images
- Convert inline-rendered rasters to WebP; keep originals as fallback. **Encode with Python Pillow**
  (`Image.open(x).save(y,"WEBP",quality=90,method=6)`) because `sips` can read but not write WebP here.
- Keep `og-image.png` and the JSON-LD `"logo"` as PNG (social scrapers / structured data).

## Workflow
- Verify edits with `grep -c` before committing. Confirm em-dash count is 0.
- After editing any source HTML, always run npm run build and commit the changed dist/ files in the same push. The live site only serves dist/.
- Commit messages: **no AI attribution lines.** Push only the authorized review branch normally,
  without force. Do not push to `main`, merge, mark a draft PR ready, deploy, or launch without
  separate Founder authorization.
- Do not edit or commit `_backup_*/`, `_local_backups/`, `backups/`, or `.claude/` (all gitignored;
  historical snapshots / local dev config).
- Local preview: serve with Node; `python3 -m http.server` is sandbox-blocked. `.claude/static-server.js` uses
  `require`, so under this repo's `"type": "module"` it must run from a `.cjs` copy outside the repo.
