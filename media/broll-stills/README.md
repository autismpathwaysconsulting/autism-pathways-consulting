# APC illustrative home scenes

Generated scenes for APC educational content. These depict fictional families and must not be presented as client footage, testimonials, documented outcomes or a guaranteed before-and-after result.

| Still / clip | Visual moment | Suggested overlay |
| --- | --- | --- |
| after-school-pause | Child returns home tired, parent gives space and observes | Transition demands can build before an outward reaction. |
| mealtime-pause | Child hesitates at dinner, parent allows time | Notice what feels difficult before adding another instruction. |
| bedtime-choices | Parent offers two simple bedtime picture choices | Keep the next step visible and manageable. |

The matching MP4s are four-second, silent 1920 × 1080 slow zooms made from still photos. They contain no new body movement or dialogue. Use short excerpts behind narration, with a clear illustrative label whenever an audience could reasonably interpret the scene as client footage. Avoid implying that an image demonstrates an individual child's progress.
